An index is a data structure that allows you to query your table efficiently based on 
attributes other than the primary key.
Think of it like the index at the back of a book — it lets you quickly find pages without 
reading the whole book.
In DynamoDB, indexes let you query by different attributes without scanning the entire table.



1.Local Secondary Index (LSI)

Must have same Partition Key as table
Must be created at table creation (cannot add later)
Useful for alternate sort orders

Example (Chat app):

Table Partition Key = conversationId
Table Sort Key = createdAt
LSI Sort Key = editedAt → allows you to query messages in conversation by edit time

aws dynamodb create-table \
  --table-name Messages \
  --attribute-definitions \
      AttributeName=conversationId,AttributeType=S \
      AttributeName=createdAt,AttributeType=N \
      AttributeName=editedAt,AttributeType=N \
  --key-schema \
      AttributeName=conversationId,KeyType=HASH \
      AttributeName=createdAt,KeyType=RANGE \
  --local-secondary-indexes '[
      {
        "IndexName": "EditedIndex",
        "KeySchema":[
          {"AttributeName":"conversationId","KeyType":"HASH"},
          {"AttributeName":"editedAt","KeyType":"RANGE"}
        ],
        "Projection":{"ProjectionType":"ALL"}
      }
  ]' \
  --billing-mode PAY_PER_REQUEST \
  --endpoint-url http://localhost:8000

read index
aws dynamodb query \
  --table-name Messages \
  --key-condition-expression "conversationId = :c" \
  --expression-attribute-values '{":c":{"S":"c1"}}' \
  --endpoint-url http://localhost:8000



2.Global Secondary Index (GSI)

Can have different Partition Key and Sort Key than the main table
Can be added anytime
Lets you query any attribute efficiently

Example (Chat app):

Table attributes: conversationId, createdAt, read
GSI: Partition Key = read, Sort Key = createdAt → fetch unread messages efficiently

aws dynamodb update-table \
  --table-name Messages \
  --attribute-definitions AttributeName=read,AttributeType=S \
  --global-secondary-index-updates '[
      {
        "Create": {
          "IndexName": "ReadIndex",
          "KeySchema":[
            {"AttributeName":"read","KeyType":"HASH"},
            {"AttributeName":"createdAt","KeyType":"RANGE"}
          ],
          "Projection":{"ProjectionType":"ALL"},
          "ProvisionedThroughput":{"ReadCapacityUnits":5,"WriteCapacityUnits":5}
        }
      }
  ]' \
  --endpoint-url http://localhost:8000

read index
aws dynamodb query \
  --table-name Messages \
  --index-name ReadIndex \
  --key-condition-expression "#r = :val" \
  --expression-attribute-names '{"#r":"read"}' \
  --expression-attribute-values '{":val":{"S":"false"}}' \
  --endpoint-url http://localhost:8000
